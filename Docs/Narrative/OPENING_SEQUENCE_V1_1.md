Статус: implementation baseline + dialogue rewrite

## 1. Locked staging

Не змінювати без окремого рішення:

- машина їде безперервно під час всього road intro;
- КПК відкривається поверх руху машини;
- старі повідомлення Касира видно як історію чату;
- після нової переписки КПК сам ховається;
- машина рухається живо, не ідеально по spline;
- дощ, бризки, двірники;
- на КПП чути рацію;
- Гугл має налобний ліхтар;
- перша аномалія зупиняється завчасно;
- пес підсвічується коротким camera cue і direction callout;
- перехід до хаба без loading blackout;
- protected reveal: ліс → стежка → туман → hub streaming → control lock → персонажі самі йдуть → zoom out → невеликий time-pass → музика → ZONE-UA;
- cinematic reveal використовується тільки при першому вході;
- skip через hold Space;
- “Пропустити пролог” у new game;
- dialogue modes: bubbles / cinematic strip / КПК.
