# Zone-UA — Narrative Design Index

Статус: working canon / implementation baseline  
Версія: v0.4  
Оновлено: 2026-10-08

Ця папка фіксує поточний наративний канон Zone-UA після реалізації прологу та Hub 2.0. Вона не замінює технічні документи про combat, inventory, save/load, world generation чи NPC AI. Тут визначено: що є каноном, які постановочні моменти не можна ламати, як говорять персонажі, як будується Act 0 до 24.02.2022, які квести та контрактні патерни використовуються, і які нові механіки виправдані контентом.

## Документи

- [LORE_AND_ACT0.md](./LORE_AND_ACT0.md) — лор, часовий каркас, персонажі, правила подачі, структура Act 0 та перехід 24.02.
- [OPENING_SEQUENCE_V1_1.md](./OPENING_SEQUENCE_V1_1.md) — поточна постановка прологу + повний rewrite діалогів.
- [QUESTS_AND_CONTRACTS.md](./QUESTS_AND_CONTRACTS.md) — персональні квест-лінії, нелінійність, reusable mechanics, procedural contract grammar.
- [HUB_2_0.md](./HUB_2_0.md) — канонічна роль Hub 2.0, protected intro reveal, просторова логіка, точки для майбутніх schedule/scene overrides.

## Статуси

- **LOCKED** — не змінювати без окремого рішення автора.
- **CANON** — поточний наративний канон.
- **WORKING CANON** — використовувати в реалізації, але допускається уточнення.
- **PROPOSED** — дизайн-напрямок, що потребує перевірки в грі.
- **DEPRECATED** — старий варіант, не використовувати.

## Загальні правила

1. Gameplay-first. Сюжет не повинен перетворювати extraction loop на коридор.
2. Світ існує незалежно від героя. Частина подій відбувається без quest marker.
3. Не кожна цікава подія є квестом. Використовувати ambient opportunities і environmental storytelling.
4. Не писати діалоги як пояснення механік. Спочатку людина, потім функція.
5. Не робити punchline після кожної другої репліки.
6. Немає random wandering у хабі як базової поведінки. Schedule буде доданий поверх semantic activity anchors.
7. 24.02 — anchor event. Його не можна пропустити через випадковий procedural raid.
8. Реальні історичні події відтворюються обережно і документально. Альтернативно-історичний аномальний шар не подається як пояснення реального вторгнення.
